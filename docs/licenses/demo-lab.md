## 개발 예시 3종

- 파일: `frontend/src/features/demo-lab/samples/fixtures/`
- 제작: 이번 개발에서 기본 타원·원·선으로 직접 작성한 기하 도형. 외부 스티커·작가 작품·브랜드 캐릭터를 복사하지 않음.
- 재현 코드: `samples/create-fixtures.cjs` (저장소 루트에서 실행).
- 범위: 개발 서버의 `?fixture=1` UI 검증 전용. 실제 생성 기능 결과나 작가 허락 작품이 아니므로 운영 샘플 기준을 충족했다고 표시하지 않음.
- 글꼴: 개발기기 기본 글꼴로 렌더링. 공개용 결과에는 별도 검증된 폰트와 라이선스를 적용해야 함.
- AI: 개발 코드 작성에 AI 사용. 제품의 이미지 생성 API로 만든 캐릭터가 아님.

## 공개 샘플 등록 시 필수 기록

1. 원본 파일명·SHA-256, 제작자 또는 생성 기능 프로젝트 ID·생성 날짜·모델.
2. 작가 작품이면 공개 웹 표시, 공개 Git 저장소 포함, PNG·ZIP 다운로드 및 발표 녹화 이용을 허용한 서면 범위. 서비스 인터뷰 참여 동의는 작품 공개 허락을 대신하지 않음.
3. 최종 렌더링 폰트명·버전·라이선스 파일·출처.
4. 실제 서비스 처리 일시·OCR·번역 후보·정리본·최종 PNG별 QA 리포트.
5. AI 생성 여부, 변경 내용, 확인 담당자·확인 날짜.

원문 이메일이나 개인정보는 공개 저장소에 넣지 않는다. 권리 근거의 공개 가능한 요약과 내부 증빙 위치만 기록한다. 체크리스트는 법적 안전을 보증하지 않는다.
