# UI/UX implementation and verification

작업 기간: 2026-10-11–12. 기존 초록색 브랜드, 로고, 마스코트, URL, SSR 공개 페이지와 저장 데이터 형식을 유지하면서 작업 화면과 복구 동선을 정리했다.

## 반영 사항

- **대시보드·보관함:** 현지화와 생성 프로젝트를 하나의 목록으로 통합했다. 이름·생성 설명 검색, 종류·상태 필터, 생성일·이름 정렬을 제공하며 검색 조건은 URL에 유지한다. 진행 중인 작업은 10초 간격의 조회와 탭 복귀 시 조회로 갱신한다. 조회 중에도 기존 카드는 유지한다.
- **목록 복구:** 두 목록의 API 실패를 독립적으로 처리한다. 일부 실패, 전체 실패, 실제 빈 목록, 검색 결과 없음이 각각 구분된다. 이름 변경·삭제·다시 열기는 기존 저장 작업을 먼저 완료하고 프로젝트 종류와 ID를 함께 사용한다.
- **공통 화면:** 본문 건너뛰기, 하나의 본문 영역, 번역된 오류·세션 복구 안내, 경고와 성공 알림 구분, 대화상자의 포커스 유지·Escape·복귀 처리를 적용했다. 일반·인증·생성 요청 오류는 HTTP 상태, 오류 코드, Retry-After 정보를 보존한다. 429·5xx·연결 오류 안내를 번역했다.
- **편집·결과:** 입력·색상·스위치·범위 조절에 이름과 선택 상태를 보완했다. OCR 영역 확인을 공통 대화상자로 전환하고 모바일 편집 도구 접기를 추가했다. 언어 국기가 깨지는 환경에서도 언어 이름을 읽을 수 있다. 결과 화면에서 이미지·언어 수를 확인할 수 있다.
- **생성·검토:** 생성의 5단계 진행 표시와 계획 입력 이름을 추가했다. 검토 화면은 규격 확인·유사 작품·AI 피드백으로 구분하고 편집 화면으로 돌아갈 수 있다. 선택이 바뀐 뒤 도착한 이전 피드백은 표시하지 않는다. 손상된 이미지가 섞여도 정상 이미지의 규격 검사 결과는 유지한다.
- **공개 화면:** 서비스, 지원, 법률 문서, 가격 안내, 404, 로그인 콜백, 기존 랜딩을 공통 기본 요소에 맞췄다. 가격 안내의 준비 중 상태와 법률 문구를 유지했다. 공개 페이지의 스크립트를 전체 미디어 로드 뒤로 미루던 처리를 낮은 우선순위의 즉시 시작으로 바꿔 초기 메뉴 조작의 지연을 줄였다. 반복되는 브랜드 표제, 과도한 그림자·배경 효과·호버 효과와 사용하지 않는 오로라·중복 목록 코드를 제거했다.
- **상단 메뉴:** 워크스페이스·서비스 소개·가격 이름을 누르면 해당 페이지로 이동한다. 중복된 ‘살펴보기’ 항목을 제거하고, 별도의 펼침 버튼으로 모바일에서도 생성·현지화·검토 및 사용법·GitHub 항목을 연다. 사용법 링크는 다른 페이지와 같은 페이지에서 모두 해당 제목 아래로 이동하며 고정 헤더가 제목을 가리지 않는다. 같은 링크를 다시 눌러도 이동한다. 터치·키보드로 연 메뉴가 이전 마우스 위치 때문에 닫히지 않도록 하고, Escape는 메뉴를 연 항목으로 포커스를 돌려준다.

## 검증

2026-10-12에 사용자가 선택한 `/sub1` 디자인을 메인 하단에 적용했다. 흰색 배경에 제작 문구와 PC·모바일 작업 화면을 나란히 배치하고 모바일에서는 세로로 배치한다. 메인과 `/sub1`은 같은 `LandingEnding`을 사용한다. 간결한 푸터를 적용하고 대형 `THANK YOU CREATOR` 문구를 제거했다. 기기 이미지는 지연 로딩하며 비교 메뉴는 샘플 페이지에만 표시한다.

배포용 미리보기에서 320·390·768·1024·1440px × 4개 언어의 20개 메인 화면 조합을 검사했다. 가로 넘침, 깨진 기기 이미지, 런타임 오류가 없었으며 메인의 첫 화면 위치, `/sub1`과의 동일한 구성, 워크스페이스 이동과 나머지 샘플도 확인했다. 프론트엔드 TypeScript·클라이언트·SSR 빌드와 공개 경로 6개의 사전 렌더링을 다시 통과했다. 검사 결과는 `/tmp/glocalizer-main-device/checks.json`에 있다.

상단 메뉴의 추가 이동 검사는 320·390·1280px × 4개 언어의 12개 조합에서 실행했다. 모바일은 실제 터치 이벤트로 열고 이동했다. 서비스 소개·가격·생성·현지화·검토, 다른 페이지와 같은 페이지의 사용법 링크 및 반복 이동, GitHub 새 탭을 확인했다. 키보드 포커스·Escape, 비로그인 생성의 로그인 복귀 경로, 런타임 오류도 별도로 검사했다. 공개 화면 48개 조합 검사에 터치 메뉴와 반복 사용법 이동을 추가해 통과했다. JavaScript가 없는 정적 페이지 이동은 일반 Vite 미리보기의 SPA 대체 응답 대신 기존 `vercel.json`의 경로 규칙과 빌드된 HTML을 적용해 확인했다. 최종 추가 검사 로그는 `/tmp/glocalizer-nav-all-final.log`에 있다.

로컬 Playwright와 상태를 변경할 수 있는 모의 API를 사용했다. 아래 스크립트는 실제 React 페이지·저장 큐·PNG 렌더링을 실행한다.

| 검사 | 범위 |
| --- | --- |
| 프론트엔드 빌드 | TypeScript, 클라이언트·SSR 번들, 공개 경로 6개 사전 렌더링 |
| 백엔드 빌드 | TypeScript 호환성 |
| `npm run lint` | 오류 없음. 기존 경고 6개 유지 |
| `npm run check:studio` | 9개 경로 × 4개 언어 × 5개 너비 = 180개 조합 |
| `VIEWPORT_WIDTHS=320,1024 npm run check:studio` | 추가 72개 조합 |
| `npm run check:public-pages` | 48개 언어·경로·너비 조합, 언어 전환, 터치 메뉴·반복 사용법 이동, 목차·FAQ, 저장소 차단 |
| `npm run check:projects` | 16개 목록 조합, 검색·필터·정렬·URL 유지, 작업 상태 갱신, 이름 변경·삭제, 부분·전체 오류 복구, 입력 보존, 완료 작업 다시 열기, 이전 검토 응답 무시, 손상 이미지, 오류 경계 |
| `npm run check:workflows` | 8·24장 일괄 편집·취소, 언어·영역·스타일 보존, 미리보기와 다운로드 픽셀 일치, 모바일 도구 접기, OCR 대화상자, 세션 401·503, OAuth 상태·복귀, 생성 계획 유지와 중복 유료 요청 방지 |
| `npm run check:landing` | 20개 조합, 장면 전환 60개, 영상 제어, 모션 감소, 작품 표시·오류 상태와 내비게이션 |

공개 페이지·랜딩은 `PREVIEW_URL=http://127.0.0.1:5174`로 배포용 빌드에서도 검사했다. 랜딩 행렬 20개·장면 60개를 확인한 뒤, 헤드라인·영상·모션 감소·오류·내비게이션 검사는 `LANDING_SKIP_MATRIX=1`로 별도 실행했다.

19개 경로를 390px·1440px에서 캡처한 38개 화면에서 가로 넘침, 런타임 오류, 본문 중복, 보이는 입력의 이름 누락이 없었다. `/login`은 로그인 상태에서 대시보드로 이동하며 비로그인 로그인 화면은 별도 워크플로 검사에서 확인했다.

AI slop 스캐너 후보는 **77개 파일·17개 그룹·169건 → 82개 파일·15개 그룹·130건**이다. 이는 자동 탐지 후보 수이며 결함 수가 아니다. 남은 후보에는 브랜드 초록색, 상태를 구별하는 경고 색, 실제 작업 단계 번호, 작품 데이터의 이모지, 투명도 체커보드·색상 피커, 로딩 스켈레톤처럼 기능에 필요한 표현이 포함된다.
